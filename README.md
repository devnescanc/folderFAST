# ⚡ Fold FAST v6.0 — Open Source Download & Media Accelerator

**Fold FAST** es un gestor y acelerador de descargas de código abierto para Windows con extensión minimalista para Google Chrome. / **Fold FAST** is an open-source multi-threaded download and media manager for Windows with a minimalist Google Chrome extension.

## ✨ Características / Features

* **Inicio automático con Windows y Bandeja del Sistema (System Tray):** Se inicia junto con Windows y permanece activo en segundo plano para capturar cualquier archivo.
* **Captura Universal de Archivos, Videos y Audios:** Intercepta cualquier archivo descargado en Google Chrome (`.zip`, `.exe`, `.pdf`, `.docx`, `.iso`, etc.) además de videos y audios de YouTube, Facebook, Instagram, TikTok, X y cualquier sitio web.
* **Menú Superior Visible (Modo Oscuro/Claro + Español/Inglés):** Cambia el color y el idioma en tiempo real desde la barra de menú superior.
* **Doble Clic para Abrir Carpeta:** Haz doble clic sobre cualquier descarga para abrir su carpeta resaltando el archivo.
